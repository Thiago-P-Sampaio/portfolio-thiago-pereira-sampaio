## Viva+

`Viva+` é uma simples plataforma web responsiva desenvolvida utilizando o framework `Bootstrap` copilotado por `IA` como atividade solicitada pela matéria de `desenvolvimento WEB` no curso de ADS(UNICID). Trata-se de um site com  propósito de disseminar o conhecimento e o auto-cuidado através do equilibrio corpo-mente, fornecendo uma   gama de dicas, hábitos e notícias de saúde para pessoas como você começarem a cuidar e planejar o seu futuro a partir de agora.

## Como utilizar
Para utilizar este reposítório, siga os passo abaixo.

1. Clone o repositório em seu dispositivo utilizando git, ou baixe o arquivo `Zip`:
``` bash
git clone https://github.com/Thiago-P-Sampaio/VivaMais_bootstrap_simple_page.git
```
2. Abra os arquivos em um editor de código como `VSCODE` e/ou abra diretamente `index.html`
