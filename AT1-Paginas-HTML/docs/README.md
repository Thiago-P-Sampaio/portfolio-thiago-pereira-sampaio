### Leia+
`Leia+` trata-se de uma editora fícticia criada com o intuito da construção dessas páginas para atividade em desenvolvimento WEB. As páginas foram desenvolvidas com IA GEMINI e revisadas pelo autor.

### Uso das Imagens
As imagens das respectivas pessoas utilizadas foram retiradas da plataforma `Unsplash`.
