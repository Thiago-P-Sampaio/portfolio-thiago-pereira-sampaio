### Calculadora IMC
Configura-se como uma simples página(apenas com `index.html`) que realiza o calculo de Indíce de Massa Corporal(IMC), dado a Altura(em metros) e o Peso(em Kgs). Dado pela expressão matemática:

$$
IMC = \frac{Peso\ (kg)}{Altura\ (m)^2}
$$

---
Utilizando `DOM` do JavaScript, construiu-se uma função para realizar o cálculo e conforme o resultado enquadrado, informa-se a classificação: `Abaixo do peso`, `Peso normal`, `Sobrepeso`,`Obesidade nível I, II, III`. Dispondo de uma tabela(`img`) para o usuário avaliar a classificação.
