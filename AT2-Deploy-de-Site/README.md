## Leia+ -- ATV1 -- DEPLOY
`Leia+ ` é uma plataforma web simples desenvolvida com boostrap copilotada por IA. Trata-se de um site simples com 5 páginas para uma editora de livros fícticia. Possui páginas: página inicial com os livros, sobre, contato, autores e um blog.

#### Estrutura de pastas
A estrutura busca seguir um padrão no desenvolvimento web, tanto em estruta quanto em nomenclatura de pastas.
```TXT
    projeto/
    │
    ├── css/
    │
    ├── docs/
    │
    ├── img/
    │   └── outras imagens
    │
    ├── autores.html
    ├── blog.html
    ├── contato.html
    ├── index.html
    ├── README.md
    └── sobre-nos.html

```

## Como utilizar
Para utilizar este reposítório, siga os passo abaixo.

1. Clone o repositório em seu dispositivo utilizando git, ou baixe o arquivo `Zip`:
``` bash
git clone https://github.com/Thiago-P-Sampaio/LeiaMais_simple_page_boostrap_AI.git
```
2. Abra os arquivos em um editor de código como `VSCODE` e/ou abra diretamente `index.html`
